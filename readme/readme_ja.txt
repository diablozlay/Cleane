============================================================
WIN/ZW データ検索/クリーンツール　使い方ガイド
============================================================

「ファイルをサクッと探す」＋「Windows のゴミをまとめて掃除する」ためのツールです。ZW3D（中望3D）のユーザーフォルダー整理機能も入っています。難しくないので、気楽にどうぞ

■ 1. まず権限のこと
------------------------------------------------------------
- 起動時に管理者権限を求められます（システムフォルダーの掃除やアカウント削除に必要）。
- ウィンドウに現在の状態が表示されます。
  - ● 管理者権限：問題なし。
  - ● 一般権限：システムフォルダーやアカウントなどは掃除できません。「管理者として再起動」を押せば解決。

■ 2. 3つの主な機能
------------------------------------------------------------
  ・検索 → 名前・種類・場所でファイルを探し、開く／パスをコピー／削除
  ・クリーンアップ項目 → 掃除したい Windows のゴミを選び、プレビューしてから実行
  ・ユーザーフォルダー管理 → ZW3D のユーザーフォルダーを整理（公式 User Folder Manager と同じ操作）

■ 3. ファイルを検索する
------------------------------------------------------------
1. キーワード：ファイル名やキーワードを入力。*.pdf、報告*2024 のようにワイルドカードも使えます。「種類」を選んだ場合は空欄でも OK。
2. 種類：ドキュメント／スプレッドシート／プレゼン／画像／動画／音楽／圧縮ファイル／プログラムとインストーラー／CAD・3D／一時・ログファイル、または「カスタム拡張子…」（複数はカンマか空白区切り。例：pdf, dwg, z3prt）。ZW3D 専用（すべて／一時ゴミのみ／モデルファイルのみ）もあります。
3. 場所：システムドライブ、すべてのドライブ（外付け含む）、特定のドライブ、ユーザーフォルダー、または「フォルダーを選択…」で自由に指定。
4. 名前を完全一致：オンにすると、入力したとおりの名前（例：setup.exe）だけが対象。フルネームの入力が必要です。
5. ファイルを完全に削除：オンにすると、結果画面の「削除」がごみ箱を通さず即・完全削除になります。取り扱い注意！
6. 「検索」を押す（入力欄で Enter でも OK）。表示は最大 200,000 件。多すぎたらキーワードを絞ってください。途中で「検索を停止」もできます。

▼ 検索結果の画面
- 上の絞り込み欄で、名前やパスでさらに絞れます。
- 列：名前／場所／サイズ／更新日時。
- ダブルクリックか Enter でファイルの場所を開きます（ファイルを選択した状態）。右クリックでその他のメニュー。
- ボタン一覧：

  ・ファイルの場所を開く → エクスプローラーでファイルを選択表示
  ・フォルダーを開く → 所属フォルダーを開く
  ・ファイルを開く → ファイルを開く（実行ファイル／スクリプトは確認が出ます）
  ・パスをコピー → フルパスをコピー（右クリックでファイル名のコピーも可）
  ・すべて選択／すべて解除 → 1つのボタンで切り替え。「すべて選択」後は「ファイルを削除」「完全に削除」「閉じる」だけが押せます
  ・ファイルを削除 → ごみ箱へ移動（あとで復元可。Shift を押しながらクリックで完全削除）
  ・完全に削除 → ごみ箱を通さず削除。元に戻せません（Shift+Delete）
  ・検索を停止／閉じる → そのままの意味です

- 削除前には必ず確認が出ます。Windows やプログラムのフォルダー内のファイルが含まれるとシステムファイル警告が追加で出るので、よく考えてください。
- 使用中や権限不足のファイルはスキップされ、件数が結果に表示されます。使っているプログラムを閉じるか、管理者として実行して再挑戦を。

■ 4. Windows のゴミを掃除する
------------------------------------------------------------
リスク別に3グループ、色分けされています。

● おすすめ（SAFE） — 最初からチェック済み
- 一時ファイル *.tmp / *._mp（システムドライブ全体）
- システム／ユーザーの一時フォルダー
- インターネット一時ファイル（IE／旧 Edge のキャッシュ）
- 最近使ったファイルの一覧
- Prefetch（次回起動が一度だけ少し遅くなります）

● 詳細項目（注意） — 確認してからチェック
- ごみ箱を空にする（全ドライブ、復元不可）
- ログファイル *.log（一部プログラムの記録が消えます）
- *.gid / *.chk / *.old
- Windows バックアップファイル *.bak
- Cookies（旧 IE／Edge。サイトからログアウトされます）
- Windows ディスク クリーンアップ（cleanmgr）：先に「ディスク クリーンアップの設定…」で項目を選んでおく

● 危険項目 — 元のバッチファイル由来の削除。元に戻せません
- システムドライブの \d フォルダーごと削除
- aspnet ユーザーアカウントの削除（古い IIS/.NET 環境のみ）
- 危険項目をチェックすると、まず2段階の警告が出ます。両方で OK を押さないとチェックされません。わからないなら触らないで！

▼ 下部のボタン
- すべて選択（危険項目を除く）：SAFE と詳細項目をまとめてチェック。危険項目は対象外。
- すべて解除／既定に戻す：チェックを全部外す／初期状態（SAFE のみ）に戻す。
- プレビュー：計算するだけで何も削除しません。解放できる容量の目安がわかります。まずこれを！
- 一覧を表示：プレビュー後、掃除対象のファイル（先頭 200,000 件）を一覧表示。場所を開いて確認できます。
- クリーンアップ開始：確認後に実際に掃除。完了すると、削除数・解放容量・所要時間が表示されます。
- 停止：途中でやめたいときに。
- 下の LOG 欄に進行状況がリアルタイムで出ます。

■ 5. ZW3D ユーザーフォルダー管理
------------------------------------------------------------
公式 User Folder Manager と同じ構成・ボタン名です（ボタンは英語表記のままです）。
1. 「User Folder Manager」を開くと、PC 内の ZW3D バージョン（例：ZW3D 2025、ZW3D WuKong 2027）を自動検出します。ドロップダウンで選ぶとパスも自動で切り替わり、「開く」でフォルダーを表示できます。
2. できること：
   - Clear auto output files（自動出力ファイルの削除）
   - Clear custom configurations（カスタム設定の削除）
   - Clear temp files（一時ファイルの削除）
   - Clear user folder（ユーザーフォルダーを空にする）
   - Save current custom configuration（現在の設定をバックアップ）／Import backup configuration（バックアップを復元）
   - Delete subfolders...：消したいサブフォルダーを選んで Delete selected（削除後は工場出荷状態に戻ります）
3. 対象フォルダーが存在しないボタンはグレーアウトします（掃除不要）。
4. 重要：実行中の ZW3D は終了されます。先に保存して ZW3D を閉じてください。削除前にもう一度確認が出ます。設定を残したいなら、先に「Save current custom configuration」を。

■ 6. 言語の切り替え
------------------------------------------------------------
15 言語に対応（中国語 繁体/簡体、English、日本語、한국어、Deutsch、Français、Español、Italiano、Português、Polski、Čeština、Magyar、Русский、Türkçe）。言語メニューから選ぶと自動で再起動し、ウィンドウサイズもそのまま保たれます。

■ 7. ひとこと注意
------------------------------------------------------------
- まずプレビュー、それから実行が一番安全です。
- 「完全削除」は本当に消えます。ごみ箱でも救えません。
- 意味がわからない項目はチェックしない。危険項目は自信がなければ触らない。
- ZW3D のフォルダーを掃除する前に、必ず ZW3D を閉じる。
- ウィンドウの位置・サイズと言語設定は %AppData%\SystemJunkCleaner に保存されます。

では、気持ちよくお掃除して PC をサクサクに！
