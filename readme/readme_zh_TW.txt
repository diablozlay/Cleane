============================================================
WIN/ZW 資料搜尋/清理工具　使用說明
============================================================

這是一個「找檔案 + 清垃圾」的小工具：能幫你在電腦裡快速搜尋檔案，也能一鍵清掉 Windows 的暫存垃圾，還內建 ZW3D（中望3D）用戶目錄的清理功能。不用緊張，跟著下面走就好

■ 1. 先看這個：權限
------------------------------------------------------------
- 程式啟動時會要求系統管理員權限（清系統資料夾、刪帳號都需要）。
- 視窗上會顯示目前狀態：
  - ● 系統管理員權限：一切正常。
  - ● 一般權限：系統資料夾、帳號等項目會清不掉。可按「以系統管理員重新啟動」補救。

■ 2. 三大功能一覽
------------------------------------------------------------
  ・搜尋 → 依檔名／類型／位置找檔案，找到後可直接開啟、複製路徑或刪除
  ・清理項目 → 勾選要清的 Windows 垃圾，先預覽，再開始清理
  ・用戶目錄管理器 → 清理 ZW3D 的使用者目錄（跟官方 User Folder Manager 一樣的動作）

■ 3. 搜尋檔案
------------------------------------------------------------
1. 關鍵字：輸入檔名或關鍵字。支援萬用字元，例如 *.pdf、報告*2024。若已選了「類型」，關鍵字可以留空。
2. 類型：文件、試算表、簡報、圖片、影片、音樂、壓縮檔、程式與安裝檔、CAD / 3D 圖檔、暫存與記錄檔；也可選「自訂副檔名…」（多個用逗號或空白分隔，例如 pdf, dwg, z3prt）。另有 ZW3D 專用類型：ZW3D 全部／僅暫存垃圾／僅模型檔。
3. 位置：系統磁碟、所有磁碟（含外接裝置）、指定磁碟機、使用者資料夾，或「選擇資料夾…」自己挑。
4. 完全符合名稱：打勾後，檔名必須和輸入內容一模一樣（例如 setup.exe），此時一定要輸入完整檔名。
5. 永久刪除檔案：打勾後，結果視窗的「刪除」會直接永久刪除、不進資源回收筒。小心使用。
6. 按「搜尋」（或在輸入框按 Enter）。搜尋最多顯示 20 萬筆，太多的話請把關鍵字寫得更精確。搜尋中可按「停止搜尋」。

▼ 搜尋結果視窗
- 上方的篩選框可以在結果裡再用名稱或路徑過濾。
- 欄位：名稱、位置、大小、修改日期。
- 雙擊或按 Enter＝開啟檔案所在位置（並選取該檔案）；右鍵有更多選項。
- 按鈕說明：

  ・開啟檔案位置 → 在檔案總管中選取該檔案
  ・開啟資料夾 → 開啟所在資料夾
  ・開啟檔案 → 直接開啟（執行檔／指令檔會先問你要不要執行）
  ・複製路徑 → 複製完整路徑（右鍵還能複製檔名）
  ・全選 / 全不選 → 同一顆按鈕切換。按「全選」後，只有「刪除檔案」「永久刪除」「關閉」可按
  ・刪除檔案 → 移到資源回收筒，之後還能還原（按住 Shift 再點＝永久刪除）
  ・永久刪除 → 不經資源回收筒，無法還原（快速鍵 Shift+Delete）
  ・停止搜尋 / 關閉 → 字面上的意思

- 刪除前會跳出確認視窗。如果檔案在 Windows 或程式安裝資料夾裡，會多給一次「系統檔案警告」，看到請三思。
- 檔案正在使用中或權限不足會被略過，並在結果訊息中告訴你有幾個沒刪成功；可先關閉佔用的程式，或用系統管理員身分再試。

■ 4. 清理 Windows 垃圾
------------------------------------------------------------
項目依風險分成三區，並以顏色標示：

● 建議清理（SAFE） — 預設就是勾選的
- 暫存檔 *.tmp / *._mp（掃描整個系統磁碟）
- 系統與使用者暫存資料夾
- 網際網路暫存檔（IE／舊版 Edge 快取）
- 最近使用的文件清單
- 預讀檔 Prefetch（清完下次開機會慢一次，之後就恢復）

● 進階項目（注意） — 請確認後再勾選
- 清空資源回收筒（所有磁碟，無法復原）
- 記錄檔 *.log（部分程式的紀錄會消失）
- *.gid / *.chk / *.old
- Windows 備份檔 *.bak
- Cookies（舊版 IE／Edge，網站會被登出）
- Windows 磁碟清理（cleanmgr）：需先按「設定磁碟清理…」勾好要清的項目

● 危險項目 — 原批次檔中的刪除動作，無法復原
- 刪除系統磁碟上的 \d 整個資料夾
- 刪除 aspnet 使用者帳號（只有舊版 IIS/.NET 才會有）
- 勾選任何一個危險項目時，會先跳出兩段式警告，兩段都按「確定」才會勾選成功。不懂就別亂勾！

▼ 底部按鈕
- 全選（不含危險項）：一次勾好 SAFE 與進階項目，危險項不會被勾。
- 全不選／還原預設：清空勾選／回到預設勾選（只勾 SAFE）。
- 預覽：只計算，不刪任何東西，告訴你大概能釋放多少空間。強烈建議先按這個。
- 檢視清單：預覽完後，列出將被清理的檔案（最多前 20 萬筆），可直接開啟檔案位置確認。
- 開始清理：確認後正式清理。完成後會顯示刪除了幾個檔案、釋放多少空間、花了多久。
- 停止：清理途中想反悔就按這個。
- 下方的 LOG 區會即時顯示執行紀錄。

■ 5. ZW3D 用戶目錄管理器
------------------------------------------------------------
介面與官方 User Folder Manager 對應，按鈕名稱也一樣：
1. 開啟「用戶目錄管理器」，程式會自動偵測本機的 ZW3D 版本（例如 ZW3D 2025、ZW3D WuKong 2027），在下拉選單選版本即可，路徑會自動帶出，也能按「開啟」直接打開該資料夾。
2. 可用的動作：
   - 清除自動輸出文件
   - 清除自訂配置
   - 清除暫存文件
   - 清空用戶目錄
   - 保存當前自訂配置（備份）／導入備份配置（還原）
   - 刪除子目錄…：勾選要刪的子目錄，按「刪除所選」；「刪除後，回復原廠設定」
3. 目標資料夾不存在的按鈕會變灰（不需要清理）。
4. 重要：清除操作會退出中望3D，請先存檔、關閉 ZW3D；刪除前也會再確認一次。想保留自己的設定？先「保存當前自訂配置」再清。

■ 6. 換語言
------------------------------------------------------------
程式支援 15 種語言（中文繁／簡、English、日本語、한국어、Deutsch、Français、Español、Italiano、Português、Polski、Čeština、Magyar、Русский、Türkçe）。從語言選單選一個，程式會自動重新啟動並套用，視窗大小會保留。

■ 7. 小提醒（建議都看一下）
------------------------------------------------------------
- 先預覽，再清理，這是最穩的習慣。
- 「永久刪除」＝真的不見，連資源回收筒都救不回來。
- 看不懂的項目就別勾；怕出事就別動「危險項目」。
- 清理 ZW3D 前務必先關閉 ZW3D。
- 視窗大小、位置與語言設定存放在 %AppData%\SystemJunkCleaner。

祝你清得開心、電腦跑得更快！
