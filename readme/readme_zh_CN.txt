============================================================
WIN/ZW 数据搜寻/清理工具　使用说明
============================================================

这是一个「找文件 + 清垃圾」的小工具：能帮你在电脑里快速搜寻文件，也能一键清掉 Windows 的暂存垃圾，还内置 ZW3D（中望3D）用户目录的清理功能。不用紧张，跟着下面走就好

■ 1. 先看这个：权限
------------------------------------------------------------
- 程序启动时会要求系统管理员权限（清系统文件夹、删账号都需要）。
- 窗口上会显示目前状态：
  - ● 系统管理员权限：一切正常。
  - ● 一般权限：系统文件夹、账号等项目会清不掉。可按「以系统管理员重新启动」补救。

■ 2. 三大功能一览
------------------------------------------------------------
  ・搜寻 → 依文件名／类型／位置找文件，找到后可直接打开、复制路径或删除
  ・清理项目 → 勾选要清的 Windows 垃圾，先预览，再开始清理
  ・用户目录管理器 → 清理 ZW3D 的用户目录（跟官方 User Folder Manager 一样的动作）

■ 3. 搜寻文件
------------------------------------------------------------
1. 关键字：输入文件名或关键字。支持通配符，例如 *.pdf、报告*2024。若已选了「类型」，关键字可以留空。
2. 类型：文档、试算表、演示文稿、图片、视频、音乐、压缩档、程序与安装档、CAD / 3D 图档、暂存与记录档；也可选「自订扩展名…」（多个用逗号或空白分隔，例如 pdf, dwg, z3prt）。另有 ZW3D 专用类型：ZW3D 全部／仅暂存垃圾／仅模型档。
3. 位置：系统磁盘、所有磁盘（含外置设备）、指定磁盘机、用户文件夹，或「选择文件夹…」自己挑。
4. 完全符合名称：打勾后，文件名必须和输入内容一模一样（例如 setup.exe），此时一定要输入完整文件名。
5. 永久删除文件：打勾后，结果窗口的「删除」会直接永久删除、不进回收站。小心使用。
6. 按「搜寻」（或在输入框按 Enter）。搜寻最多显示 20 万笔，太多的话请把关键字写得更精确。搜寻中可按「停止搜寻」。

▼ 搜寻结果窗口
- 上方的筛选框可以在结果里再用名称或路径过滤。
- 字段：名称、位置、大小、修改日期。
- 双击或按 Enter＝开启文件所在位置（并选取该文件）；右键有更多选项。
- 按钮说明：

  ・开启文件位置 → 在资源管理器中选取该文件
  ・开启文件夹 → 打开所在文件夹
  ・开启文件 → 直接打开（运行档／指令档会先问你要不要运行）
  ・复制路径 → 复制完整路径（右键还能复制文件名）
  ・全选 / 全不选 → 同一颗按钮切换。按「全选」后，只有「删除文件」「永久删除」「关闭」可按
  ・删除文件 → 移到回收站，之后还能还原（按住 Shift 再点＝永久删除）
  ・永久删除 → 不经回收站，无法还原（快速键 Shift+Delete）
  ・停止搜寻 / 关闭 → 字面上的意思

- 删除前会跳出确认窗口。如果文件在 Windows 或程序安装文件夹里，会多给一次「系统文件警告」，看到请三思。
- 文件正在使用中或权限不足会被略过，并在结果消息中告诉你有几个没删成功；可先关闭占用的程序，或用系统管理员身分再试。

■ 4. 清理 Windows 垃圾
------------------------------------------------------------
项目依风险分成三区，并以颜色标示：

● 建议清理（SAFE） — 缺省就是勾选的
- 暂存盘 *.tmp / *._mp（扫描整个系统磁盘）
- 系统与用户暂存文件夹
- 互联网暂存盘（IE／旧版 Edge 缓存）
- 最近使用的文档清单
- 预读档 Prefetch（清完下次开机会慢一次，之后就恢复）

● 高端项目（注意） — 请确认后再勾选
- 清空回收站（所有磁盘，无法复原）
- 记录档 *.log（部分程序的纪录会消失）
- *.gid / *.chk / *.old
- Windows 备份档 *.bak
- Cookies（旧版 IE／Edge，网站会被注销）
- Windows 磁盘清理（cleanmgr）：需先按「设置磁盘清理…」勾好要清的项目

● 危险项目 — 原批量档中的删除动作，无法复原
- 删除系统磁盘上的 \d 整个文件夹
- 删除 aspnet 用户账号（只有旧版 IIS/.NET 才会有）
- 勾选任何一个危险项目时，会先跳出两段式警告，两段都按「确定」才会勾选成功。不懂就别乱勾！

▼ 底部按钮
- 全选（不含危险项）：一次勾好 SAFE 与高端项目，危险项不会被勾。
- 全不选／还原缺省：清空勾选／回到缺省勾选（只勾 SAFE）。
- 预览：只计算，不删任何东西，告诉你大概能释放多少空间。强烈建议先按这个。
- 查看清单：预览完后，列出将被清理的文件（最多前 20 万笔），可直接开启文件位置确认。
- 开始清理：确认后正式清理。完成后会显示删除了几个文件、释放多少空间、花了多久。
- 停止：清理途中想反悔就按这个。
- 下方的 LOG 区会即时显示运行纪录。

■ 5. ZW3D 用户目录管理器
------------------------------------------------------------
接口与官方 User Folder Manager 对应，按钮名称也一样：
1. 开启「用户目录管理器」，程序会自动侦测本机的 ZW3D 版本（例如 ZW3D 2025、ZW3D WuKong 2027），在下拉列表选版本即可，路径会自动带出，也能按「开启」直接打开该文件夹。
2. 可用的动作：
   - 清除自动输出文档
   - 清除自订配置
   - 清除暂存文档
   - 清空用户目录
   - 保存当前自订配置（备份）／导入备份配置（还原）
   - 删除子目录…：勾选要删的子目录，按「删除所选」；「删除后，回复原厂设置」
3. 目标文件夹不存在的按钮会变灰（不需要清理）。
4. 重要：清除操作会退出中望3D，请先存盘、关闭 ZW3D；删除前也会再确认一次。想保留自己的设置？先「保存当前自订配置」再清。

■ 6. 换语言
------------------------------------------------------------
程序支持 15 种语言（中文繁／简、English、日本语、한국어、Deutsch、Français、Español、Italiano、Português、Polski、Čeština、Magyar、Русский、Türkçe）。从语言菜单选一个，程序会自动重新启动并套用，窗口大小会保留。

■ 7. 小提醒（建议都看一下）
------------------------------------------------------------
- 先预览，再清理，这是最稳的习惯。
- 「永久删除」＝真的不见，连回收站都救不回来。
- 看不懂的项目就别勾；怕出事就别动「危险项目」。
- 清理 ZW3D 前务必先关闭 ZW3D。
- 窗口大小、位置与语言设置存放在 %AppData%\SystemJunkCleaner。

祝你清得开心、电脑跑得更快！
