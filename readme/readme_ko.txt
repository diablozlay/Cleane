============================================================
WIN/ZW 데이터 검색/정리 도구　사용 설명서
============================================================

「파일을 빠르게 찾기」＋「Windows 쓰레기 한 번에 치우기」를 해 주는 도구입니다. ZW3D(중망3D) 사용자 폴더 정리 기능도 들어 있어요. 어렵지 않으니 편하게 따라와 주세요

■ 1. 먼저 권한 이야기
------------------------------------------------------------
- 시작할 때 관리자 권한을 요청합니다(시스템 폴더 정리, 계정 삭제에 필요).
- 창에 현재 상태가 표시됩니다.
  - ● 관리자 권한: 문제 없음.
  - ● 일반 권한: 시스템 폴더, 계정 등은 정리되지 않습니다. 「관리자 권한으로 다시 시작」을 누르면 해결!

■ 2. 3가지 핵심 기능
------------------------------------------------------------
  ・검색 → 이름/종류/위치로 파일을 찾고, 열기·경로 복사·삭제
  ・정리 항목 → 치우고 싶은 Windows 쓰레기를 체크 → 미리 보기 → 정리
  ・사용자 폴더 관리자 → ZW3D 사용자 폴더 정리(공식 User Folder Manager와 같은 동작)

■ 3. 파일 검색하기
------------------------------------------------------------
1. 키워드: 파일 이름이나 키워드를 입력합니다. *.pdf, 보고서*2024 같은 와일드카드도 됩니다. 「종류」를 골랐다면 비워 둬도 OK.
2. 종류: 문서, 스프레드시트, 프레젠테이션, 이미지, 동영상, 음악, 압축 파일, 프로그램/설치 파일, CAD·3D, 임시·로그 파일, 또는 「사용자 지정 확장명…」(여러 개는 쉼표나 공백으로 구분, 예: pdf, dwg, z3prt). ZW3D 전용(전체/임시 쓰레기만/모델 파일만)도 있습니다.
3. 위치: 시스템 드라이브, 모든 드라이브(외장 포함), 특정 드라이브, 사용자 폴더, 또는 「폴더 선택…」으로 직접 지정.
4. 이름 완전 일치: 켜면 입력한 이름과 정확히 같은 파일만 찾습니다(예: setup.exe). 전체 파일명을 입력해야 합니다.
5. 파일 영구 삭제: 켜면 결과 창의 「삭제」가 휴지통을 거치지 않고 바로 영구 삭제됩니다. 조심하세요!
6. 「검색」을 누르세요(입력창에서 Enter도 가능). 최대 200,000건까지 표시되며, 너무 많으면 키워드를 더 구체적으로 적어 주세요. 도중에 「검색 중지」도 가능합니다.

▼ 검색 결과 창
- 위쪽 필터 입력창으로 이름이나 경로로 한 번 더 걸러낼 수 있습니다.
- 열: 이름 / 위치 / 크기 / 수정한 날짜.
- 더블클릭 또는 Enter: 파일 위치 열기(해당 파일이 선택된 상태). 오른쪽 클릭: 더 많은 메뉴.
- 버튼 설명:

  ・파일 위치 열기 → 탐색기에서 파일을 선택해 보여 줌
  ・폴더 열기 → 파일이 있는 폴더 열기
  ・파일 열기 → 파일 열기(실행 파일/스크립트는 먼저 확인)
  ・경로 복사 → 전체 경로 복사(오른쪽 클릭으로 파일명 복사도 가능)
  ・전체 선택 / 전체 해제 → 버튼 하나로 전환. 「전체 선택」 후에는 「파일 삭제」「영구 삭제」「닫기」만 눌러집니다
  ・파일 삭제 → 휴지통으로 이동(나중에 복원 가능, Shift+클릭이면 영구 삭제)
  ・영구 삭제 → 휴지통을 거치지 않음, 복구 불가(단축키 Shift+Delete)
  ・검색 중지 / 닫기 → 말 그대로입니다

- 삭제 전에는 항상 확인 창이 뜹니다. Windows나 프로그램 폴더의 파일이 포함되면 시스템 파일 경고가 추가로 뜨니 꼭 다시 생각해 보세요.
- 사용 중이거나 권한이 없는 파일은 건너뛰며, 결과 메시지에 개수가 표시됩니다. 해당 프로그램을 닫거나 관리자 권한으로 실행한 뒤 다시 시도하세요.

■ 4. Windows 쓰레기 정리하기
------------------------------------------------------------
위험도별로 3개 그룹, 색으로 구분됩니다.

● 권장 정리(SAFE) — 기본으로 체크되어 있음
- 임시 파일 *.tmp / *._mp(시스템 드라이브 전체)
- 시스템/사용자 임시 폴더
- 인터넷 임시 파일(IE/구형 Edge 캐시)
- 최근 사용 문서 목록
- Prefetch(정리 후 다음 부팅이 한 번 조금 느려집니다)

● 고급 항목(주의) — 확인 후 체크
- 휴지통 비우기(모든 드라이브, 복구 불가)
- 로그 파일 *.log(일부 프로그램 기록이 사라짐)
- *.gid / *.chk / *.old
- Windows 백업 파일 *.bak
- Cookies(구형 IE/Edge, 사이트에서 로그아웃됨)
- Windows 디스크 정리(cleanmgr): 먼저 「디스크 정리 설정…」에서 항목을 골라 두세요

● 위험 항목 — 원본 배치 파일의 삭제 동작, 복구 불가
- 시스템 드라이브의 \d 폴더 통째로 삭제
- aspnet 사용자 계정 삭제(구형 IIS/.NET에만 존재)
- 위험 항목을 체크하면 먼저 2단계 경고가 뜹니다. 두 번 모두 확인을 눌러야 체크됩니다. 모르면 건드리지 마세요!

▼ 하단 버튼
- 전체 선택(위험 항목 제외): SAFE와 고급 항목을 한 번에 체크. 위험 항목은 제외됩니다.
- 전체 해제 / 기본값 복원: 체크 전부 해제 / 기본 상태(SAFE만)로 되돌리기.
- 미리 보기: 계산만 하고 아무것도 삭제하지 않습니다. 확보할 수 있는 용량을 알려 줍니다. 꼭 먼저 눌러 보세요!
- 목록 보기: 미리 보기 후, 정리될 파일 목록(앞 200,000건)을 보여 주며 위치를 열어 확인할 수 있습니다.
- 정리 시작: 확인 후 실제로 정리합니다. 끝나면 삭제된 파일 수, 확보한 용량, 걸린 시간이 표시됩니다.
- 중지: 정리 도중 마음이 바뀌면 누르세요.
- 아래쪽 LOG 영역에 진행 상황이 실시간으로 나옵니다.

■ 5. ZW3D 사용자 폴더 관리자
------------------------------------------------------------
공식 User Folder Manager와 같은 구성·버튼 이름입니다(버튼은 영문 표기 그대로입니다).
1. 「User Folder Manager」를 열면 PC에 설치된 ZW3D 버전(예: ZW3D 2025, ZW3D WuKong 2027)을 자동으로 찾아 줍니다. 드롭다운에서 버전을 고르면 경로가 자동으로 바뀌고, 「열기」로 해당 폴더를 열 수 있습니다.
2. 사용할 수 있는 동작:
   - Clear auto output files(자동 출력 파일 삭제)
   - Clear custom configurations(사용자 지정 설정 삭제)
   - Clear temp files(임시 파일 삭제)
   - Clear user folder(사용자 폴더 비우기)
   - Save current custom configuration(현재 설정 백업) / Import backup configuration(백업 복원)
   - Delete subfolders...: 지울 하위 폴더를 골라 Delete selected (삭제 후 ZW3D가 초기 설정으로 돌아갑니다)
3. 대상 폴더가 없는 버튼은 회색으로 비활성화됩니다(정리할 것이 없음).
4. 중요: 실행 중인 ZW3D가 종료됩니다. 먼저 작업을 저장하고 ZW3D를 닫으세요. 삭제 전에 한 번 더 확인 창이 뜹니다. 설정을 보존하고 싶다면 먼저 「Save current custom configuration」을 사용하세요.

■ 6. 언어 바꾸기
------------------------------------------------------------
15개 언어를 지원합니다(중국어 번체/간체, English, 日本語, 한국어, Deutsch, Français, Español, Italiano, Português, Polski, Čeština, Magyar, Русский, Türkçe). 언어 메뉴에서 고르면 프로그램이 자동으로 다시 시작되며 창 크기도 유지됩니다.

■ 7. 마지막 당부
------------------------------------------------------------
- 먼저 미리 보기, 그다음 정리가 가장 안전한 습관입니다.
- 「영구 삭제」는 정말로 사라집니다. 휴지통도 구해 주지 못해요.
- 무슨 항목인지 모르면 체크하지 마세요. 위험 항목은 확신이 없다면 건드리지 마세요.
- ZW3D 폴더를 정리하기 전에는 반드시 ZW3D를 닫으세요.
- 창 위치/크기와 언어 설정은 %AppData%\SystemJunkCleaner에 저장됩니다.

즐겁게 정리하시고, PC가 쌩쌩해지길 바랍니다!
